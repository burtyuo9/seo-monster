# Арбитраж Трафика и TDS - Тренды 2026

## 5 Главных Трендов Арбитража 2026

### 1. Видео вместо текста
- Пользователи читают меньше длинных текстов
- TikTok, Reels, YouTube Shorts - основные источники трафика
- Текстовые лендинги заменяются интерактивными форматами
- UGC (user-generated content) - новый стандарт

**Рекомендации:**
- Вертикальные видео
- Голосовое сопровождение
- Динамичный монтаж
- Интерактивные элементы (квизы, мини-игры)

### 2. AI заменяет ручные процессы
- Нейросети генерируют креативы
- AI пишет рекламные тексты
- Автоматизированные системы оптимизируют ставки
- Чат-боты заменяют операторов
- A/B тестирование автоматизировано

**Инструменты:**
- ChatGPT для копирайтинга
- MidJourney для креативов
- Автоматические bid managers
- AI-аналитика для воронок

### 3. Классические источники трафика теряют эффективность
- Google и Meta ужесточают модерацию
- Push-уведомления перегружены спамом
- CTR падает
- Нативный трафик дорожает

**Новые источники:**
- Telegram Ads
- TikTok Native
- Мессенджеры
- Метавселенные
- Invite-only партнёрки

### 4. Команды превращаются в холдинги
- Крупные студии строят бизнес-структуры
- Контроль целых вертикалей (loans, gambling, nutra)
- Соло-арбитражникам сложнее конкурировать
- Доступ к лучшим офферам ограничен

**Стратегия:**
- Присоединяться к сильным командам
- Партнёрство с другими арбитражниками
- Фокус на узких нишах

### 5. Законодательство усложняет работу
- Платёжные системы блокируются
- Рекламная цензура усиливается
- KYC проверки усложняют вывод средств
- Контроль криптовалют растёт

**Решения:**
- Иностранные юрлица
- Wise, Revolut для платежей
- Работа в менее регулируемых GEO (Азия, Латинская Америка, Африка)

## TDS (Traffic Distribution System)

### Основные функции TDS:
1. **Трекинг кликов** - отслеживание каждого перехода
2. **Распределение трафика** - по правилам и фильтрам
3. **Фильтрация** - гео, устройство, ОС, браузер
4. **Ротация офферов** - A/B тестирование
5. **Антифрод** - блокировка ботов
6. **Постбэки** - интеграция с партнёрками

### Типы потоков (Flows):
- **Direct** - прямой редирект на оффер
- **Landing → Offer** - через прелендинг
- **Multi Landing** - ротация лендингов
- **Split Test** - A/B тестирование

### Фильтры TDS:
| Фильтр | Параметры |
|--------|-----------|
| Гео | Страна, город, регион, ISP |
| Устройство | Desktop, mobile, tablet |
| ОС | Windows, macOS, iOS, Android, Linux |
| Браузер | Chrome, Firefox, Safari, Edge |
| Язык | Язык браузера |
| IP | Whitelist/Blacklist |
| Реферер | Источник перехода |
| Время | День недели, время суток |
| Connection | WiFi, 3G, 4G, 5G |

### Антифрод методы:
1. Блокировка известных ботов (User-Agent)
2. Блокировка датацентров и VPN
3. Лимит кликов с одного IP
4. Проверка JavaScript
5. Fingerprinting браузера
6. Поведенческий анализ

### Популярные TDS/Трекеры:
1. **Keitaro** - self-hosted, гибкий
2. **Voluum** - облачный, enterprise
3. **Binom** - быстрый, self-hosted
4. **RedTrack** - облачный, простой
5. **ThriveTracker** - облачный
6. **CPV Lab Pro** - self-hosted

## Детальная документация фильтров TDS (по типу Keitaro)

### Логические операторы
- **AND** - клик проходит только если ВСЕ условия выполнены
- **OR** - клик проходит если ЛЮБОЕ условие выполнено

### IS / IS NOT
- **IS** - разрешить (клик должен иметь этот признак)
- **IS NOT** - заблокировать (клик НЕ должен иметь этот признак)

### Полный список фильтров:

### Маски и регулярные выражения:
```
* - любые символы
? - один символ
- - интервал

Примеры:
*keyword - всё до keyword
keyword* - всё после keyword
*keyword* - keyword в любом месте
/regex/ - регулярное выражение
@empty - пустое значение
```

### Типы потоков (Flows):

1. **Forced** - принудительный, проверяется первым
   - Для фильтрации ботов
   - Для блокировки нежелательного трафика

2. **Regular** - обычный поток
   - Основная логика распределения
   - Ротация по весам или позиции

3. **Default** - поток по умолчанию
   - Собирает всё что не прошло фильтры
   - Последний в цепочке

### Проверка уникальности:
- **Для потока** - уникален в текущем потоке
- **Для кампании** - уникален для всей кампании
- **Для всех кампаний** - уникален глобально

Период уникальности настраивается (1 час, 24 часа, 7 дней и т.д.)
