## 1. Введение

SEO Monster - это полностью автономный AI-агент для комплексного SEO-продвижения сайтов. Ключевая особенность версии 3.0 - **полная автономность**: система работает без внешних AI API по умолчанию, используя собственные движки для анализа и генерации контента.

### Ключевые принципы

| Принцип | Описание |
|---------|----------|
| **Автономность** | Работает без внешних API, используя собственные алгоритмы |
| **Опциональность** | Внешние AI (бесплатные/платные) подключаются по желанию |
| **Мультиязычность** | Поддержка русского и английского языков |
| **Модульность** | 11+ независимых модулей для разных задач |

## 3. Автопилот (Autopilot)

Автопилот - это сердце SEO Monster. Он автоматически выполняет полный цикл SEO-задач.

### Статусы автопилота

| Статус | Описание |
|--------|----------|
| `Running` | Активно выполняет задачи |
| `Paused` | Приостановлен, можно продолжить |
| `Stopped` | Полностью остановлен |

### Управление

**Запуск автопилота:**
```bash
curl -X POST http://localhost:8000/api/autonomous/start
```

**Остановка:**
```bash
curl -X POST http://localhost:8000/api/autonomous/stop
```

**Пауза:**
```bash
curl -X POST http://localhost:8000/api/autonomous/pause
```

**Продолжение:**
```bash
curl -X POST http://localhost:8000/api/autonomous/resume
```

### Цикл работы

1. **Выбор сайта** → Автопилот выбирает сайт из списка
2. **Анализ** → Запускает внутренний анализатор
3. **Извлечение ключевых слов** → Определяет темы для контента
4. **Генерация** → Создает SEO-оптимизированные статьи
5. **Сохранение** → Записывает результаты
6. **Повтор** → Переходит к следующему сайту

### Быстрая генерация

Для немедленной генерации без ожидания очереди:

```bash
curl -X POST http://localhost:8000/api/autonomous/generate \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "SEO оптимизация для начинающих",
    "language": "ru",
    "content_type": "guide",
    "word_count": 1500
  }'
```

### Типы контента

| Тип | Описание | Структура |
|-----|----------|-----------|
| `guide` | Полное руководство | Введение → Что это → Почему важно → Как работает → Преимущества → Лучшие практики → Ошибки → FAQ → Заключение |
| `how_to` | Пошаговая инструкция | Введение → Подготовка → Шаги 1-6 → Заключение |
| `listicle` | Статья-список | Введение → Пункты 1-10 → Заключение |
| `comparison` | Сравнение | Введение → Критерии → Сравнительная таблица → Рекомендации → Заключение |

## 4. Управление сайтами (Sites)

### Добавление сайта

```bash
curl -X POST http://localhost:8000/api/autonomous/sites \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "name": "Мой сайт",
    "language": "ru"
  }'
```

### Получение списка сайтов

```bash
curl http://localhost:8000/api/autonomous/sites
```

### Удаление сайта

```bash
curl -X DELETE "http://localhost:8000/api/autonomous/sites?url=https://example.com"
```

### Немедленный запуск для сайта

```bash
curl -X POST http://localhost:8000/api/autonomous/run-now \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "language": "ru",
    "articles_count": 3
  }'
```

## 8. Прогрев домена (Warm-up)

Автоматический прогрев нового email-домена для улучшения доставляемости.

### Стратегии прогрева

| Стратегия | Длительность | Риск |
|-----------|--------------|------|
| Conservative | 21 день | Низкий |
| Moderate | 14 дней | Средний |
| Aggressive | 7 дней | Высокий |

### Создание плана

1. Перейдите в "Email SES" → "Warm-up"
2. Нажмите "Новый план прогрева"
3. Выберите стратегию и домен
4. Включите Auto-Executor для автоматической отправки

## 9. A/B Тестирование

Оптимизация email-кампаний через сплит-тестирование.

### Что можно тестировать

- Тема письма
- Содержание письма
- Время отправки
- Имя отправителя

### Процесс

1. Создайте тест с вариантами A и B
2. Система отправит каждый вариант части аудитории
3. Победитель определяется по Open Rate или Click Rate
4. Победивший вариант отправляется остальным

## 10. TDS и Трекер

### TDS (Traffic Direction System)

Распределение трафика по правилам:

- По географии (страна, город)
- По устройству (мобильный, десктоп)
- По источнику (Facebook, Google)
- По времени

### Трекер

Отслеживание эффективности кампаний:

| Метрика | Описание |
|---------|----------|
| Clicks | Общее количество кликов |
| Unique Clicks | Уникальные посетители |
| Conversions | Целевые действия |
| CR | Конверсия (%) |
| EPC | Доход на клик |
| ROI | Возврат инвестиций |

## 13. Настройки

### Общие настройки

| Параметр | Описание | Значения |
|----------|----------|----------|
| Язык | Язык интерфейса | `ru`, `en` |
| Тема | Цветовая схема | `light`, `dark` |

### Настройки автопилота

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| auto_analyze | Авто-анализ сайтов | `true` |
| auto_generate | Авто-генерация контента | `true` |
| articles_per_day | Статей в день | `5` |
| min_word_count | Минимум слов | `800` |
| external_ai_enabled | Внешний AI | `false` |

### Обновление настроек

```bash
curl -X PUT http://localhost:8000/api/autonomous/settings \
  -H "Content-Type: application/json" \
  -d '{
    "auto_analyze": true,
    "auto_generate": true,
    "articles_per_day": 10,
    "external_ai_enabled": false
  }'
```

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/autonomous/status` | Статус автопилота |

| POST | `/api/autonomous/stop` | Остановка |

| POST | `/api/autonomous/resume` | Продолжение |

```bash

# 2. Запустить анализ и генерацию

  -H "Content-Type: application/json" \
  -d '{"url": "https://mysite.com", "language": "en", "articles_count": 5}'

# 3. Проверить результаты
curl http://localhost:8000/api/autonomous/articles
```
