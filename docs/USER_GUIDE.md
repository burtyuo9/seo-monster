## 1. Философия: Полная Автономность

Ключевое отличие этой версии SEO Monster - **полная автономность**. Система спроектирована так, чтобы работать самостоятельно, без необходимости во внешних платных AI сервисах.

-   **Собственный движок:** SEO Monster использует встроенные движки для анализа сайтов и генерации SEO-оптимизированного контента.
-   **Без API ключей по умолчанию:** Вам не нужно вводить API ключи для начала работы.
-   **Опциональные помощники:** Внешние AI (бесплатные и платные) могут быть подключены по желанию для расширения возможностей, но они не являются обязательными.

## 2. Модуль "Автопилот" - Ваш автономный SEO-менеджер

Это главный модуль, который управляет всеми автоматическими процессами.

### 2.1. Панель управления Автопилота

На главной странице модуля вы видите:

-   **Статус:** `Running`, `Paused` или `Stopped`.
-   **Кнопки управления:** Запустить, остановить или поставить на паузу автопилот.
-   **Статистика:** Общее количество сайтов, задач в очереди, выполненных задач и сгенерированных статей.
-   **Текущая задача:** Что именно делает агент в данный момент (например, "Анализ сайта example.com").

### 2.2. Как работает Автопилот

Когда вы нажимаете **"Запустить автопилот"**, он начинает бесконечный цикл работы:

1.  **Выбор сайта:** Выбирает один из добавленных сайтов для работы.
2.  **Анализ:** Запускает **внутренний анализатор** для изучения сайта, его контента, структуры и SEO-показателей.
3.  **Поиск идей:** На основе анализа определяет темы для нового контента, которые могут улучшить SEO.
4.  **Генерация контента:** Использует **внутренний генератор** для создания уникальных, SEO-оптимизированных статей на выбранные темы.
5.  **Сохранение:** Сохраняет сгенерированные статьи в модуле "Контент".
6.  **Повтор:** Переходит к следующему сайту или задаче.

### 2.3. Быстрая генерация

На вкладке "Dashboard" внутри модуля "Автопилот" вы можете быстро сгенерировать одну статью, не дожидаясь очереди автопилота:

-   **Тема:** Введите любую тему (например, "лучшие кроссовки для бега").
-   **Язык:** Выберите язык.
-   **Тип контента:** Выберите структуру (руководство, инструкция, список).
-   Нажмите **"Сгенерировать статью"**.

### 2.4. Логи

На вкладке "Логи" вы можете в реальном времени видеть все действия, которые выполняет автопилот. Это помогает понять его "мыслительный" процесс.

## 3. Управление сайтами

На вкладке "Сайты" вы управляете списком проектов для автопилота.

-   **Добавить сайт:** Укажите URL, название и язык сайта.
-   **Запустить сейчас:** Принудительно запустить полный цикл (анализ + генерация) для конкретного сайта, не дожидаясь общей очереди.
-   **Удалить:** Убрать сайт из мониторинга.

## 4. Управление контентом

На вкладке "Статьи" вы найдете весь контент, созданный автопилотом или вами вручную.

-   **Просмотр:** Прочитайте сгенерированную статью.
-   **Информация:** Узнайте тему, количество слов, язык и дату создания.
-   **Дальнейшие действия:** В будущих версиях здесь появятся кнопки для автоматической публикации в WordPress и другие CMS.

## 5. Настройки

На вкладке "Настройки" вы можете тонко настроить работу автопилота.

-   **Авто-анализ сайтов:** Включить/выключить автоматический анализ.
-   **Авто-генерация контента:** Включить/выключить автоматическую генерацию.
-   **Статей в день:** Установить лимит на количество генерируемых статей.
-   **Минимум слов:** Задать минимальный объем для одной статьи.

### Опциональный Внешний AI

Здесь же находится секция **"External AI (Optional)"**. По умолчанию она выключена.

Если вы хотите, чтобы SEO Monster использовал внешние API (например, бесплатный Groq или платный OpenAI) для более качественной или разнообразной генерации, вы можете:

1.  Включить опцию **"Enable external AI assistance"**.
2.  Перейти в общие настройки системы (боковое меню "Settings" -> "AI Providers") и добавить ваши API ключи.

**Даже с включенной опцией, SEO Monster будет пытаться сначала использовать собственные ресурсы, и только в сложных случаях обращаться к внешним помощникам.**

## 6. Диагностика
